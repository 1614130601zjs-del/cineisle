# iOS PWA 使用说明

映屿 CineIsle 的 iOS 免费方案是 Web/PWA：不需要 Apple Developer 账号，也不需要 TestFlight。

## 安装到主屏幕

1. 用 Safari 打开你的映屿 Render 地址。
2. 点底部分享按钮。
3. 选择「添加到主屏幕」。
4. 从桌面图标打开「映屿」。

## 能做什么

- 创建/加入房间
- 本地选择视频播放
- 播放、暂停、进度同步
- 聊天、弹幕、笔记、卡片
- 导入 SRT/VTT/ASS/SSA 字幕
- 同步当前字幕和最近字幕给后端
- 手动上传当前视频帧给 AI 看一眼

## 限制

- 不能控制别的 App。
- 不能后台常驻。
- 不能偷偷截屏。
- 重新打开后通常需要重新选择本地视频文件。
